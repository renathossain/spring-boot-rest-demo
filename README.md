# spring-boot-rest-demo

- Goto https://start.spring.io/, add "Spring Web" dependency, and click "Generate".
- This downloads a .zip file, extract it and add the files to your repo. Check to make sure the hidden files (e.g. `.gitignore`) are also added.
- Check and change if necessary he Java version to match an installed version on your system (e.g. `JavaLanguageVersion.of(26)`).
- Build and run the project: `./gradlew bootRun`.
- Visit to see the app: http://localhost:8080
- Start developing in `src/main/java/com/example/demo/DemoApplication.java`
